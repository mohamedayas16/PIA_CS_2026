## 1. Project Overview

This repository contains the Final Integrative Project (PIA)
for the Scientific Computing course.

The project is organized into three phases:

1. A documented and reproducible GitHub repository.
2. A Python pipeline that retrieves scientific data from a
   real API and processes the data into Parquet format.
3. A Power BI data model and report used to investigate
   a scientific research question.
